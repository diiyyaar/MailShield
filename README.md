# 🛡️ MailShield

MailShield is a simple phishing email detection web application that helps users identify suspicious emails using keyword-based analysis. It provides a risk level (Low, Medium, or High) along with safety recommendations to increase cybersecurity awareness.

---

## 📌 Problem Statement

Phishing emails are one of the most common cyber threats. Many users unknowingly click malicious links or share sensitive information because they cannot identify phishing attempts.

---

## 💡 Solution

MailShield analyzes the content of an email and checks for common phishing indicators such as:
- Urgent language
- Password requests
- OTP requests
- Suspicious verification prompts
- "Click Here" links

Based on these indicators, it classifies the email as:
- 🟢 Low Risk
- 🟡 Medium Risk
- 🔴 High Risk

It also provides safety recommendations for the user.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Paste an email into the analyzer.
5. Click **Analyze Email** to view the result.
